# Data Engineering Curriculum

A structured Python curriculum for learning data engineering from the ground up — covering pipelines, SQL, cloud tooling, and production patterns used in real fintech and eCommerce environments.

---

## Who It's For

Engineers moving into data engineering from software development or analytics, who want a practical, hands-on curriculum rather than a theory-heavy course.

---

## What's Covered

| Module | Topics |
|--------|--------|
| Python for Data | File I/O, data structures, type hints, error handling |
| SQL Foundations | Joins, window functions, CTEs, query optimization |
| Pipeline Design | ETL vs ELT, idempotency, incremental loads, backfill patterns |
| Cloud Storage | S3, BigQuery, Athena — reading, writing, partitioning |
| Orchestration | Airflow DAG design, retries, sensors, task dependencies |
| Stream Processing | Kafka concepts, consumer groups, offset management |
| Testing | Unit tests, integration tests, data quality checks |
| Production Patterns | Logging, alerting, schema evolution, SLA monitoring |

---

## Approach

- **Project-first** — every module builds toward a working pipeline, not a toy example
- **Real tooling** — same stack used in Israeli fintech: PostgreSQL, BigQuery, Airflow, Python
- **Incremental complexity** — each module extends the previous one; nothing starts from scratch

---

## Stack

Python 3.10+, PostgreSQL, BigQuery, AWS (S3 / Athena / Glue), Apache Airflow, Apache Kafka, Spark (intro module)

---

*Curriculum is actively maintained alongside production data engineering work in banking and eCommerce.*
